# To Do List
## О проекте
### Описание 
Данный проект представляет из себя небольшое учебное приложения типа ToDo. 
Для его создания используются HTML5, CSS3, JavaScript
### Использования проекта
Для того чтобы открыть проект нужно открыть файл Index.html в папке Html
